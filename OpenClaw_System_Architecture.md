## 组件详细说明

### 1. 网关层 (Gateway Layer)

| 组件 | 功能 | 技术 |
|------|------|------|
| HTTP API Server | RESTful API 接口 | Express/Fastify |
| WebSocket Server | 实时双向通信 | WS Library |
| Channel Adapters | 多平台协议适配 | Platform SDKs |
| Auth Router | Token验证、白名单、路由分发 | JWT + Middleware |

### 2. 核心服务层 (Core Service Layer)

| 组件 | 功能 | 存储 |
|------|------|------|
| Session Manager | 会话生命周期管理 | Memory + SQLite |
| Memory System | 三层记忆架构 | SQLite + Vector DB |
| Cron Scheduler | 定时任务、Heartbeat | Node-Cron |

### 3. AI 引擎层 (AI Engine Layer)

| 提供商 | 模型 | 特点 |
|--------|------|------|
| Moonshot | Kimi K2.5 | 长上下文(256K)、中文优化 |
| Anthropic | Claude 3 | 推理强、安全高 |
| OpenAI | GPT-4/GPT-4o | 能力强、生态好 |
| Local | Ollama | 私有化、离线可用 |

### 4. 工具与技能层 (Tools & Skills Layer)

| 类别 | 工具示例 | 用途 |
|------|---------|------|
| 数据 | query_database, search_files | 信息查询 |
| 网络 | web_search, http_request | 外部API |
| 系统 | read_file, execute_command | 本地操作 |
| 通讯 | send_email, send_message | 对外通信 |

## 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| **进程模型** | 多进程 (Gateway分离) | 稳定性、可扩展性 |
| **通信协议** | WebSocket + HTTP | 实时性 + 兼容性 |
| **存储方案** | SQLite + JSON | 简单、零运维 |
| **AI集成** | 多Provider抽象 | 不绑定单一厂商 |
| **扩展机制** | Skills系统 | 热插拔、易开发 |

## 总结：核心层次

```
┌─────────────────────────────────────────┐
│  表现层：微信/钉钉/邮件等用户界面         │
├─────────────────────────────────────────┤
│  接入层：Gateway（认证+路由）             │
├─────────────────────────────────────────┤
│  业务层：Session + Memory + Cron          │
├─────────────────────────────────────────┤
│  智能层：AI Provider（多模型支持）        │
├─────────────────────────────────────────┤
│  能力层：Tools + Skills（可扩展）         │
├─────────────────────────────────────────┤
│  存储层：SQLite + JSON + Vector           │
└─────────────────────────────────────────┘
```

**记忆口诀**：表接业智能存（表现-接入-业务-智能-能力-存储）
